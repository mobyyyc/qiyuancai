# Qiyuan Cai

Personal website built with Next.js and TypeScript.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run build` for a production build.

Edit the introduction and contact links in `src/app/page.tsx`, projects in
`src/data/projects.ts`, experience in `src/data/experience.ts`, and styling in
`src/app/globals.css`.
